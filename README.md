# Sales Incentive Compensation Management (ICM) Simulation

## Project Overview

This project is a hands-on simulation of a Sales Incentive Compensation Management (ICM) system, designed to understand how incentive plans are structured, sales performance is evaluated, payouts are calculated, and results are validated.

The project covers the end-to-end incentive calculation workflow, combining business rule design, data modelling, Excel-based calculations, SQL analysis, validation controls, and product documentation.

## Project Objectives

- Understand the fundamentals of Incentive Compensation Management (ICM).
- Design a structured sales incentive plan with eligibility criteria, thresholds, accelerators, and payout caps.
- Build an incentive calculation model using Microsoft Excel.
- Organise employee, product, sales, and target data using SQLite.
- Implement incentive calculation logic using SQL.
- Validate payout calculations and identify data exceptions.
- Document business requirements, user stories, acceptance criteria, and workflows.

## Disclaimer

This is an independent learning and simulation project developed using fictional data and illustrative business assumptions.

It does not represent an actual company's incentive compensation policy, a production implementation, or hands-on configuration of an enterprise ICM platform such as Varicent.
